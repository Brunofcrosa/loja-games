## 📋 Sobre o Projeto

A **Loja Games** é um site estático desenvolvido com tecnologias web fundamentais (HTML, CSS e JavaScript) sem uso de frameworks. O projeto apresenta um catálogo de jogos com tela de login e navegação simples — ideal como estudo de front-end básico.

---

## ✨ Funcionalidades

- 🔐 Tela de login
- 🎮 Listagem de jogos disponíveis
- 🎨 Estilização com CSS puro
- ⚡ Sem dependências externas

---

## 🚀 Tecnologias

| Tecnologia | Uso |
|---|---|
| HTML5 | Estrutura das páginas |
| CSS3 | Estilização e layout |
| JavaScript | Interatividade |

## 📁 Estrutura

```
loja-games/
├── index.html      # Página principal
├── login.html      # Tela de login
├── css/            # Folhas de estilo
├── js/             # Scripts JavaScript
└── img/            # Imagens e assets
```

---

## ⚙️ Como Executar

Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão **Live Server** no VS Code.
